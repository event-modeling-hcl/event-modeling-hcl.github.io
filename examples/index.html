Examples

Each canvas has switchable Model, Compact, Storming (Event Storming-like), and Context Map views.

The source models are .em.hcl files in the emhcl v0.17.0 tool repository. A model can be one file or a folder of files.

These examples show language and workflow patterns. They are not proof of a complete business process. Review field origins, failure paths, and scenarios with domain experts before using a model for implementation.
