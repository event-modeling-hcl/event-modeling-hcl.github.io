This page shows every shared component from assets/site.css and assets/site.js. Use it to check a theme or component change in light and dark mode before the change ships.

Body copy uses IBM Plex Sans at a readable line length. A Read Model makes facts usable. It is more than "some projection." field_type is a reusable concept that other blocks reference by traversal, not by string.

Links in prose use ink color with a thin underline. Hover a link to make the underline thicker.

Callouts

A callout has a thin left rule and no fill. The rule is gray for notes, clay for rules and targets, and red for warnings.

Block labels use lower snake_case, so every identity is safe to traverse.

After this stage, every shared component renders correctly in both themes at mobile and desktop widths.

No question, no Read Model.

An automation workflow must not consume an event from an external bounded context. That case is a Translation.

Buttons

The primary button has a flat top and rounded bottom corners. Other buttons have square corners. Keyboard focus adds an outline without changing the shape. Disabled buttons do not change on hover.
